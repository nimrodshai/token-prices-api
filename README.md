# Token Prices API

Public LLM token pricing, generated by GitHub Actions and hosted on GitHub Pages.
No running server, paid hosting, LLM calls, or API keys are required.

The API is independent from product repositories. PPP, Assistyca, and other
applications can consume the same URL.

## API

Use these canonical JSON endpoints:

- Prices: https://nimrodshai.github.io/token-prices-api/api/openai/prices.json
- Snapshot status: https://nimrodshai.github.io/token-prices-api/api/health.json

The price response retains `prices`, `pricesByModel`, `fetchedAt`, and all
existing pricing fields. Amounts are USD per one million tokens and use standard
short-context rates. Where separate cache-write durations are listed,
`cache_write` is the 30-minute rate. `fetchedAt`
records when the snapshot was generated; `fetched` is false because reading a
snapshot does not fetch the upstream source. The health response describes the
published snapshot, with the same `fetchedAt` timestamp.

Legacy GET paths `/api/openai/prices`, `/api/prices`, `/api/prices/openai`, and
`/api/health` also work under the Pages base URL. They redirect to directory
indexes containing the same JSON, served as `text/html`. Prefer the `.json`
endpoints for the correct `application/json` content type.

## Refreshes and deployment

The **Publish token prices** workflow fetches OpenAI's public pricing markdown
and publishes a fresh snapshot every Monday at 06:00 UTC, on pushes to `main`,
and when manually run through **Actions → Publish token prices → Run workflow**.
Pull requests run tests and build the snapshot without deploying it. If fetching
or parsing fails, the workflow fails and the last successful deployment remains
available. Check `fetchedAt` when data freshness matters.

Each successful build also archives `data/openai-prices.json` in the repository.
These weekly data commits keep the public repository active so GitHub does not
disable its schedule after 60 days without activity. Commits made with the
workflow token do not trigger another workflow run.

GitHub Pages must be enabled with **Settings → Pages → Source → GitHub Actions**.

This static API replaces the Render service at
`https://token-prices-api.onrender.com`. Consumers must update their configured
URL to the GitHub Pages endpoint above. Query parameters such as `?refresh=1`
do not trigger an upstream refresh. `POST /internal/prices/refresh` and refresh
secrets are replaced by the authenticated GitHub Actions workflow.

## Local development

Run tests (explicit discovery includes the `tests/` directory):

```bash
python3 -m unittest discover -s tests -v
```

Build and preview exactly the files that GitHub Pages publishes:

```bash
python3 scripts/build_static_api.py
python3 -m http.server 8899 --directory _site
curl http://127.0.0.1:8899/api/openai/prices.json
```

For offline builds, pass `--source /path/to/pricing.md`. Use `--output /path/to/site`
to change the output directory. Generated files in `_site/` are ignored by Git.

Verify the live deployment, including JSON content types, CORS, snapshot freshness,
and all legacy GET paths:

```bash
python3 scripts/check_published_api.py
```

Pass `--base-url https://your-host/base-path` to check another deployment.

The original Python server remains available for local integrations requiring
on-demand refreshes:

```bash
python3 scripts/run_token_pricing_server.py --host 127.0.0.1 --port 8899
```

Its optional environment settings are `TOKEN_PRICES_CACHE_TTL_SECONDS` (defaults
to one week) and `TOKEN_PRICES_REFRESH_SECRET`. These only affect the local
server; hosted refreshes are controlled by the workflow schedule.
